# 接入指南

指南记录如何检查现有模型、映射其语义并测试转换路径，面向使用真实资产的实践者，也面向尚未熟悉所有 2D 创作生态的贡献者。

推荐的流程以证据为先。从展示一项能力的小型资产开始，记录源工具与版本、导出设置、涉及的资源和目标运行时，再以其他贡献者可以重复的方式比较结果。

## 计划中的指南

- 导出最小模型包。
- 映射骨骼与动画数据。
- 声明不支持的能力。
- 验证运行时转换。

## 一份有用的指南报告

实践报告应包含原始资产或最小可复现替代品、相关包文件、源与目标版本以及能力矩阵。对每项能力标明它是被保留、转换、采样、忽略还是阻断，并在确实能解释可见差异时附截图或短视频；机器可读结果与文字说明仍然是主体。

## 保持实验小而清楚

大型角色项目很难判断究竟是哪种关系造成差异。优先为一个参数、一项约束、一个遮罩或一个事件制作单独实验。理解行为后，再把案例合并为更大的 fixture，并加入参考实现的验证集。

## 报告不确定性

如果格式行为没有文档支持，应当明确写出。一次导出的观察是证据，并不自动成为普遍规则。在把假设写入规范模块前，应标记假设，并寻求第二个实现或维护者确认。
