# 介绍

Future2D 是面向 2D 模型互操作的开放研究项目。不同工具会以不同方式描述同类资产：一个角色可能有层级、可绘制部件、变形、动画、物理和交互状态。项目关注这些资产在工具之间流动时涉及的数据与运行时行为。

当前站点收录共同术语、模块草案、兼容性记录和现有项目的参考资料，属于早期工作文档。稳定的 schema、二进制编码和一致性计划尚未发布。

## 正在研究的问题

- 模型包如何在工具之间标识可绘制部件、关节、参数和动画事件？
- 哪些数据属于可移植模型包，哪些数据属于渲染器或应用？
- 转换器如何说明被省略或替换的功能？
- 针对一个具体用途，需要什么测试案例来支撑兼容性结论？

## 初始范围

初始模块包括包结构、模型图、动画数据、可选物理行为、运行时求值和验证。2D 文件既可能含有视觉资源，也可能含有运行时需要计算的行为，因此交换记录需要说明保存的数据以及求值条件。

例如，目标端可以绘制纹理，却生成不同的参数关系、裁剪结果、约束结果或事件顺序。兼容性记录应列出测试资产、源端与目标端版本、测试功能和实际输出。

## 阅读方式

可先阅读[核心概念](/zh/docs/concepts)，再查看[规范草案](/zh/docs/specification/)和[兼容性](/zh/docs/compatibility)。研究某个生态时，建议从可复现的小型资产开始，并记录源工具、版本、导出设置、目标运行时、测试功能和可见结果。
