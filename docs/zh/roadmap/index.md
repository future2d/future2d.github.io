# 路线图

Future2D 是一个开放的标准研究项目。本路线图描述研究如何逐步成为经过验证、可以互操作的基础。

<RoadmapTimeline locale="zh" />

## 阶段说明

- **研究**：梳理现有格式、运行时与创作实践。
- **草案**：把共同概念整理为可评审的规范模块。
- **参考实现**：用真实工具与运行时边界验证模型。
- **互操作**：让 2D 资产可以在生态之间可靠流动。
