# Community

Future2D grows through evidence, implementation, and careful discussion. Share compatibility findings, propose a model boundary, or help test a reference implementation.

- [Visit the GitHub organization](https://github.com/future2d)
- [Read the documentation](/docs/)

## Useful contributions

- Document how an existing format represents models, animation, physics, or runtime state.
- Add compatibility evidence and small reproducible conversion examples.
- Review specification language for ambiguity and implementation cost.
- Build or test reference implementations against real authoring tools.
