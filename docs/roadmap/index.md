# Roadmap

Future2D is an open standard research effort. The roadmap lists the work needed to turn observations into tested modules and interoperable implementations.

## What each phase means

- **Research** maps existing formats, runtimes, and authoring practices.
- **Draft** turns shared concepts into precise, reviewable modules.
- **Reference implementation** tests the model against real tools and runtime boundaries.
- **Interoperability** compares independent implementations using the same fixtures and records the remaining differences.
