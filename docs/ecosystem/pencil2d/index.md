## Origin and ownership

The Future2D repository named pencil2d is a fork of the upstream Pencil2D source repository, whose canonical GitHub name is `pencil2d/pencil`. Pencil2D describes itself as a volunteer-driven free and open-source animation and drawing project. Future2D retains a forked copy for research; the upstream community retains ownership, maintenance, and project governance.

## Compatibility scope

Pencil2D supports **traditional hand-drawn 2D animation** using both bitmap and vector graphics. Its upstream README lists Windows, macOS, Linux, and FreeBSD as supported platforms. This is an authoring scope different from bone-driven, deformation-driven, or facial-tracking avatar systems: drawings and frames are primary, while a runtime may need to preserve timing, layers, artwork references, and vector or bitmap distinction.

The upstream documentation does not list Spine, DragonBones, or Live2D editor compatibility for this project.

## Why Future2D catalogs it

Pencil2D provides evidence for a frame-oriented, drawing-first pipeline. It helps identify where a future standard may need optional animation or artwork modules alongside rigged model data.

## Role of the Future2D fork

The fork is a research reference for traditional-animation authoring. Its native project files remain part of the Pencil2D project and are not described here as Future2D format data.
